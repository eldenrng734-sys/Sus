WHAT IT MEANS
Shared rules so every endpoint looks and behaves the same.

1. PAGINATION
   - Request:  ?page=1&page_size=20
   - Response: { items: [...], total, page, page_size }
   - Reusable: PaginationParams dependency + Page[T] schema

2. ERRORS
   - One JSON format: { error: { code, message, request_id } }
   - AppError base class + subclasses (NotFound, Forbidden, Conflict)
   - Exception handlers for AppError and validation errors

3. REQUEST IDs
   - Middleware generates a unique ID per request
   - Returned in the X-Request-ID header
   - Included in error responses and logs

4. LOGGING
   - Structured logs: request_id, tenant_id, user_id, route, status, duration
   - NEVER log passwords, tokens or message text
